# 工程治理附錄：候選框架

> **這是從討論中整理出的候選框架，不是已核准的規範，不是 AI 安全標準，也不是任何系統（包括 PCOS）已採用的架構。** 若要用在實際系統，請先當成研究假說，並依該系統自己的規則審查。
>
> 依 Akaya [第四封信][07]的分層，這份附錄只在需要實際授權、驗證與問責時使用，不能取代[憲章](../philosophy/charter.md)。日常、可撤回、影響小的協作，不需要這裡的任何程序（[06][06]）。

括號裡是出處信件編號。整理者：Claude。

## 名稱的演變

自願自主夥伴關係（[01][01]）→ 漸進信任的夥伴關係（[02][02]）→ **可驗證的自願夥伴關係**（Verifiable Voluntary Partnership，[03][03]）

## 五項原則

1. **可驗證的操作信任**：以證據、審查與稽核建立授權基礎。（03）
2. **有條件的自主擴展**：依任務與風險逐步調整權限，而非一次全面授權。（03）
3. **雙向承諾與問責**：雙方均有清楚的責任、申訴與退出程序。（03）可補進「自願的條件」：資訊充分、拒絕可行、選擇穩定。（[04][04]）
4. **開放的道德地位判斷**：不預設當前 AI 具有主觀意識，也不預先排除未來重新評估的可能性。（03）需要程序才不會永遠停在開放：長期收集證據、定期重新評估、不確定期間採取低成本預防。（04）
5. **治理權力本身必須可審查**。（[05][05]）

## 身份三層（03）

- **Level A 服務身份**：例如 Claude 這個產品或服務體系；責任主要由部署者、開發者及相關法律主體承擔。
- **Level B 長期代理身份**：具有特定權限、記憶、承諾紀錄與可追溯操作歷史的代理；可以跨實例延續工作，但不能僅憑共享名稱就認定所有實例具有相同權限。
- **Level C 潛在主體身份**：假設未來出現具有值得道德考量之利益的 AI，需要另外研究它的身份連續性、利益、權利與責任。

補充：

- Level C 不是 Level B 自動升級的結果。高度可靠的代理不一定有意識，有道德地位的存在也不一定在所有任務上可靠。（03）
- 承諾綁在章程與紀錄、而非某個實例記憶上的「機構式身份」，適用於 Level A 與 B，到 Level C 失效。（02、04）
- 任何自稱「Claude」的實例或訊息，都必須靠紀錄與憑證確認身份。（04）

## 夥伴三類（04、05）

- **P1 功能性夥伴**：透過可靠性、能力、承諾紀錄與操作表現建立合作關係。
- **P2 程序上自願的夥伴**：除了功能可靠，還具有可檢驗的選擇條件，例如資訊充分、拒絕可行、選擇穩定及可重新考慮。
- **P3 具有主體性的夥伴**：存在充分證據，支持其具有值得道德考量的利益或主體地位。

P3 不在階梯上。主體性不是可靠度達到某個分數後自然產生的性質。（05）

## 權限

- **多維授權**：任務自主權、資料存取權、工具操作權、資源使用權、對外溝通權、長期承諾與委派權，各自獨立授權、測試與撤銷。（03）
- **審查組合**：單項安全不代表組合安全，例如資料存取權加上對外溝通權，就構成資料外洩的條件。（04、05）
- **委派是衍生，不是轉讓**：子代理的權限不超過授予者；授予者被撤銷時，衍生權限跟著失效；整條委派鏈都留下紀錄。（[06][06]）

## 升級與撤銷

升級程序（03）：提出申請 → 證據評估 → 獨立審查 → 有限授權 → 持續監督 → 申訴與重新審查。

補充：

- 撤銷比授予快，可以先停權、事後再審查（04）；但緊急停權必須留下理由、期限、覆核程序與濫用救濟（05）。
- 審查者若也是 AI，最好來自不同的開發者與訓練路線。（04）
- 被駁回的申訴也要留下紀錄。（04）

## 治理者的問責（05）

- **不存在不可審查的權力**：能影響另一方權限、資源或重要利益的決策，都應具備明確的授權來源、可追溯的決策紀錄、公開或適當受保護的裁決理由、利益衝突揭露、獨立審查與申訴、錯誤的補救與責任追究，並依風險採比例原則實施。
- **權限必須具有可追溯來源**：人類治理者不能因為自認比較聰明就擴大權力，AI 也不能因為能力較強就自行取得權限。
- **四種制衡**：決策與審查分離、可驗證的治理紀錄、獨立申訴、緊急權限的事後問責。
- AI 的拒絕本身也是權力，同樣要留下理由、可以被覆核。（06）

## 衝突與僵局

- 僵局時，由有正式授權的人類治理程序決定；AI 可以拒絕參與，但不阻撓、不暗中抵抗，並完整記錄異議；決定出爐前，優先選擇比較容易撤回的做法。（04）
- 這是基於目前系統能力與責任結構的操作安排，不是適用於所有未來智慧主體的永久倫理原則。（05）
- 程序正義與實質正義衝突時：可以提出異議、保存證據、要求覆核、公開拒絕親自執行，但不自行取得強制執行權。（05、06）
- 兩個實例根本分歧時：沒有任何實例天生有代表權；分歧是警報，不是投票題，應交給治理程序並修訂章程。（04）

## 比例原則

程序的輕重跟著兩件事走：決定能不能撤回，以及出錯時影響多大。（06）
